Unofficial Bonus Exercise



Objective:

Migrate an Angular JS component to Angular 2 ao that both Angular JS and Angular 2 components run in the same application.

  • git clone https://github.com/vsavkin/ng1ng2router.git

  • Open ng1ng2router in an editor.

  • In a terminal window:

  • npm install

  • npm start

  • http://localhost:8080/

  • Click inbox – This is an AngularJS component we will migrate

  • Click on a message This is an Angular 2 component

  • http://localhost:8080/settings

  • These are all A2 components

  • Open ng1ng2router/src/messages/message_text_cmp.ts – this is an Angular 2 component we can use as a template



Create a new MessagesComponent

  • Create a new file: ng1ng2router/src/messages/messages_cmp_a2.ts

  • Copy the content of message_text_cmp.ts into it as a starting point.

  • Change the class name in messages_cmp_a2.ts to MessagesComponent

  • Copy the template from MessagesCmp and replace the template in your MessagesComponent. Replace the content of the <h1> tag with "Messages from Angular 2".

  • Copy the content of the MessagesController to your new class (replacing the old class content)

  • Remove $routeParams from the constructor

  • Change the initialisation of this.folder to be "inbox"

Hint:


export class MessageTextCmp {

folder: string;

messages: Message[];


constructor( repository: Repository) {

this.folder = "inbox";

this.messages = repository.messagesFor(this.folder);

}

}


  • Fix the template (replace ng-repeat with *ngFor and remove the reference to ctrl)

Update the Module



  • Open ng1ng2router/src/messages/index.ts

  • Remove any code related to MessagesCmp add MessagesComponent to the declarations section of NgModule

  • Add an imports section as shown to the NgModule:


imports : [ CommonModule,

RouterModule.forChild([

{ path: 'messages', component: MessagesComponent },


])],


  • At the bottom of the file, duplicate the MessagesModule.directive section and modify it to define the MessagesComponent. (There are no inputs).

Build and Test

  • Stop the npm process which you started at the beginning of the exercise (CTRL+C).

  • Run npm start again. This should build the project.

  • Fix any errors

  • Stop the npm start process and try again.
